RideWeave

A shared voice for the ride.

Offline group intercom for riders. Phones link directly over Wi-Fi Aware and Bluetooth LE, and each one relays voices to the next — no mobile network needed.

About the product

On a mountain pass there is often no signal. RideWeave doesn't need one: the riders' phones form a mesh network and pass the group's voices along, from the first bike to the last.

No network needed

Phones talk directly to each other, with no SIM data and no server.

A mesh that stretches

Each phone relays audio to the next, so the group can spread out.

iPhone and Android together

One open protocol, documented on the product site.
